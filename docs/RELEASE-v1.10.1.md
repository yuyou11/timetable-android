# v1.10.1 两处小修：占位格标签与时间轴行布局

在 v1.10.0（`periods` 节数信息）基础上的补丁版，只修了两处小问题，无新功能。

## 修复 1：单节占位格显示成「第 2-2 节」

作息模板里写单节占位格（`"nodes": [2, 2]`）时，没课的时段原来会显示
**「第 2-2 节 · 无课」**——没有哪种课表是这么写的。现在单节显示
**「第 2 节 · 无课」**，多节连排（如 9-10 节）的写法不变。

## 修复 2：长地点不再挤压课程名

今日页时间轴的地点列原来不限宽。课程名长、地点也长的时候
（比如「C语言与人工智能基础」+「子良楼107（公共计算机实验室一）」），
在窄屏上课程名会被挤到只剩一两个字的宽度，整行被撑得很高。
现在地点列限宽 150dp、超出显示省略号，课程名始终有正常的排版空间
（完整地点仍可在通知栏和课表页看到）。

## 兼容性

- 数据格式不变（timetable v3），老文件照常导入。
- 顺带补了 13 节制学校场景的回归测试：节次直写的课程在
  「节点 N = 学校第 N 节」的模板下，按学校节次时间渲染、不跨午休、
  课程名完整出现在时间轴上。
