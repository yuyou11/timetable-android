# v1.10.2 时间轴行重排：地点挪到标题下方，课名不再被挤竖

修一个真实报障：某节课的课名在今日页时间轴上**一个字一行竖着排**，
像一根柱子。只有课名和地点都长的课会这样
（「C语言与人工智能基础」+「子良楼107（公共计算机实验室一）」），
课名短的课（足球1）完全正常。

## 原因

旧布局把地点放在**标题右边的同一行**，不限宽。屏幕宽度是固定的，
扣掉时间列、时长胶囊之后，课名和地点要瓜分剩下的宽度——
两个都长的时候，课名只剩一两个字的宽度，TextView 只能一字一行竖着排。

v1.10.1 试过「给地点限宽 150dp」——治标不治本：屏幕本来就窄，
限完地点课名还是没剩多少。

## 修法

**地点挪到标题下方单独一行**（备注行之下，样式不变仍是强调色）：

```
09:45          C语言与人工智能基础        [1时25分]
11:10          子良楼107（公共计算机实验室一）
```

标题从此永远占满一整行宽度，竖排从根上不可能再发生；
长地点只在超过一整行时才显示省略号。

## 兼容性

- 数据格式不变（timetable v3）。
- 新增布局结构回归测试（`TimelineRowLayoutTest`）守住这个结构。
