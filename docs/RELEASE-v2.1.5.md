# v2.1.5 PERSONA 3 收口：今天页、课表页、点格弹卡

这一版把 P3 彩蛋缺的两页补上，五个页签终于同一套外观了。
**默认外观（不打开彩蛋）一个像素都没动**，所以不想看 P3 的同学升级后也不会觉得哪里变了。

## 一、今天页 v3 —— 整页重画

以前是「给原布局逐控件刷皮」：顶部一条 HUD 横幅，下面还是原来那些卡片。
现在按 `p3web/today-p3-v3.html` 整页重画：

- **上半屏蓝 HUD**：巨号日期 + 三角旗（旗里写当天周几）、此刻时间、星期、周次 / 日型，
  常驻开关从一整行卡片收成右上角一颗胶囊；
- **下半屏斜口白纸**：24 小时色带（每段宽度 = 那段时间的分钟数）、此刻卡（NOW 标签 / 进度 / 接下来）、
  当前格附近几行时间线、明天卡（起床时刻 + 一键设闹钟）。

时间线**可以上下滑**：整天的格子铺在一条裁剪过的视口里，打开时当前格在正中，
往上翻能看早上那几格、往下翻能看到睡前那段，视口右边一条细滚动条表示还剩多少。
拖动超过 `touchSlop` 才算滑动，滑动松手不会误触弹卡；点某一格仍然弹信息卡。

## 二、课表页 v2 —— 整页重画

- 巨号 `WEEK` + 幽灵周次压在标题后面，品红斜条贯穿；
- 周次选择收进标题区：日期条 + 两个键帽（横滑也能翻周）；
- 网格**没有竖格线**，课是浮在蓝底上的玻璃块，跨行的同课合成一整块；
- 今天是一条**青色光柱**，表头上钉着品红 `TODAY` 胶带；
- 近五周点阵从顶部卡片挪到底部一条密度条（设置里那个开关仍然管它）。

行高按屏幕剩余高度现算，并且**只取可用高度的 2/3**（长屏铺满会把行高顶到 56dp，
10 行的表看着又稀又空）；密度条跟着网格走，再往下让出两个格子的高度 ——
网格上方留白少、下方留白多，卡片贴着网格会显得挤在中间，让两行之后上下才平衡。
`periods` 是 13 节的学校同样放得下。

## 三、点格弹卡也换皮

课表页和今天页的弹卡（`dialog_slot_courses`）在 P3 下换成黑卡 + 青字 + 描边按钮。
字段和绑定逻辑**一个字没动** —— 只换外观，以后加字段不用改两处。

## 四、蓝底统一

日历页、今天页的蓝底现在直接铺闹钟页那张 `bg_alarm_page`（渐变 + 手绘天空 + 顶部压暗），
三个页面的蓝是**同一份资源**。取不到资源时各自退回原来的自绘渐变兜底。
课表页仍是自绘渐变 —— 它满屏蓝底、上面还压着课块和光柱，铺图会更花。

## 五、顺手把两处判定收成一份

- `WeekGrid`：「哪几格合成一块」+ 近五周点阵，默认外观和 P3 外观共用 ——
  两套画法对同一份课表必须给出同一个答案；
- `PersonaTodayModel`：色带分段、时间线滚动位置（当前格居中 + 两头夹取）、格子状态、时段配色。

新增 26 条单元测试（合计 **446 条**，全部跑在电脑上）。

## 八、修：闹钟页上滑时「下滑 · 查看闹钟」不跟着动

闹钟页 v4 是「表盘固定、白纸从下面盖上来」，上滑时表盘 / 数字钟 / 日期整组只做
0.32 倍的上移（parallax）。但那句「下滑 · 查看闹钟」原来挂在 **heroInner 的兄弟层**
（直接挂在 heroLayer 上），于是别人在动、它钉在原地，看着像贴在屏幕底部没反应。

把它移进 `heroInner` 就完了 —— 现在它和表盘、数字钟、日期一起走同一个 0.32 倍：
实测同一次滚动里，数字钟顶端和这行字各上移 32px。
（对比图：`p3web/android-alarm-hint-scroll.png`）

## 九、设置页重构

**首页**（P3 模式的落地面）原来照游戏 SKILL / ITEM 那一屏临摹：几个巨号英文斜词
交错排开，真正要读的中文名缩在词尾当小字 —— 装饰压过了内容。现在改成一条竖向列表：
中文名是主标题、英文缩写退成上面那行小字、左侧 01–04 编号、右侧一枚青色方块，
底色和今天 / 表 / 日历同一张手绘天空。

**四个分类页**整套换皮（默认外观一个像素没动）：

| | 之前 | 现在 |
|---|---|---|
| 页面底 | 系统浅色 | `bg_alarm_page` 手绘天空 |
| 卡片 | 白色圆角 + 灰描边 | 深藏青直角 + 亮蓝描边 |
| 文字 | 深灰 / 中灰 / 强调色 | 白 / 浅蓝 / 青 |
| 开关 | 主题色 | 青底 + 亮钮 |
| 勾选框 | 主题蓝方块 | 青色 |
| 按钮 | 主题扁平按钮 | 直角描边块 |
| 分隔线 | 浅灰 | 半透明蓝 |

实现是 [PersonaSettingsSkin](../app/src/main/java/com/yxz/timetable/ui/persona/PersonaSettingsSkin.kt)：
**按颜色和 drawable 的 ConstantState 认，不认 id** —— 设置页有 77 个 TextView、21 个 Button，
还有代码现搭的课程行，按 id 登记既写不完也守不住。两条坑写在 `docs/persona3/README.md` 里：
不能就地 `setColor`（会把资源缓存也染黑），`SwitchMaterial` / `CheckBox` 必须先于 `Button` 判。

## 十、闹钟表盘的细节按游戏截图对了一遍

正面视角、双圈没变，补/改的是这几处（见 [表盘特写](../p3web/android-alarm-clock-detail.png)）：

- **4 点改成 `IIII`**（原来写的 `IV`）—— 钟表商三百年的写法，游戏里也是四道竖；
- 罗马数字放大到 0.15R，正好顶满内外两圈之间那条带子，缩一号就变成刻度了；
- **轴心下方加一行 AM / PM**，字距拉开、跟走字换 —— 原图上就印在表盘里，不是指针；
- 分针加长到 0.84R（几乎碰到数字圈）、时针收到 0.52R 并加粗 —— 原图里两根的差别很明显；
- **内圈上补了 12 个筝形**：一条对角线正好落在内圈上（两个侧顶点贴圆周），
  另一条沿半径一外一内、向圆心那侧更长（0.080R）—— 原来这里是一条光溜溜的圆；
- 外圈撑到 **0.975R**、两道圈的描边加粗到 **0.024R / 0.020R**；
- 外圈尖刺：**底边钉在外圈的外沿（0.987R）**，整根都在圈外、不再把圆切成两半；
  尖顶 1.120R（12/3/6/9）/ 1.085R（其余）—— 正点只比普通点长三成多，不是长短两套；
  为了给这截尖让位，表盘主半径从 0.86×半边长收到 **0.82**。

## 七、底栏

底栏最后落成**浅灰底 + 五个窄体粗斜标签**：选中墨蓝、未选中次要灰，
中间「今天」和别的项长得一样（图标 22dp / 字号 11sp，原来是给实心圆配的 20dp / 10sp）；
栏顶那条墨蓝细线也撤了 —— 底色直接贴到页面下沿，页签切来切去时不会有一条深色线在闪。

中间试过几种装饰，都撤掉了（留个记录，别下次又想加）：

| 试过的 | 为什么撤 |
|---|---|
| 探出栏顶的蓝圆 | 圆和这一排方块字不是一套几何 |
| 裁角方板（八边形） | 比圆好，但方块比同高的圆更重，压住了邻项 |
| 扁矩形 + 深蓝边框 | 形状可以了，但仍然是「多出来的一块」 |
| 选中项背后的深藏青斜块 | 和白纸栏对比过强，像贴了张膏药 |

代码里现在只有两件事：画纸、画那条线（[PersonaNavBackdrop](../app/src/main/java/com/yxz/timetable/ui/persona/PersonaNavBubble.kt)）。
要恢复任何一版，看 git 历史。
