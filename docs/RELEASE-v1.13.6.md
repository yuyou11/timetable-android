# v1.13.6 今日页也能点格子：详情卡 + 按格子设闹钟

之前只有课表页的格子能点。今日页那条时间线是只读的 —— 想知道「这格几点结束、
在哪、备注写了什么」，只能自己从三行小字里拼。这个版本把两件事补上：
**点开看清楚**，和**顺手设个提醒**。

## 一、今日页的每一格都能点

点下去弹出的是和课表页**同一套面板**（同一个布局、同一段「从被点的格子放大
冒出来」的动画），但内容说的是这一格本身：

- 标题 + 性质徽标（上课 / 自习 / 吃饭 / 睡觉 / 训练 / 路上 / 事务 / 机动）
- 时间：`10:25 – 12:00 · 1 时 35 分`
- 教室（有就显示）
- 老师、周次（**只有课程格才有**，从 `courseId` 找回那门课）
- **备注** —— 模板里每一格的第二行字（「周三有晚课，这觉必须睡」）。
  这句话只有今日页说得出，课表页的课没有备注
- 这一格属于哪套作息（「A 型日」模板）—— 同名的一格在 A / B 型日上时刻不同，
  不写清楚，改完闹钟第二天会发现它提前了十分钟

**不是只有上课的格子能点**。这条线上真正占大多数的是「午餐」「午睡」「空档 · 机动」，
而「提醒我 12:00 去吃饭」恰恰是它们在时间线上的意义。

## 二、新闹钟类型：按格子响

课程格还是走原来的课程闹钟（只在这门课真的上的那几周才响）。
其余格子新增一种 `AlarmSource.MOMENT`：

**存的不是「07:35」这个数字，而是这一格的标签**（标题 + 性质）。
响铃时现算当天的时间轴，找得到这一格才响，时刻用**它当天的真实起点**减提前量。

这带来三个直接结果：

| 情况 | 行为 |
|---|---|
| 模板把「早读」从 07:35 挪到 07:40 | 闹钟自动跟着挪，不用重新设 |
| 那天是休息日 / 假期 / 改了模板没这一格 | 不响 |
| A / B 型日同一格的时刻不同 | 各按各的那天响 |

响铃范围两档：

- **每周对应那天**（默认）——「每周三有这个 tag 就响」
- **按日型** —— 勾上「只在「A 型日」响」，就变成「每个 A 型日都响」，
  不再限于点它的那一天。日型名跟着用户改的名字走

【怎么区分两格】比「标题 + 性质」。只比标题的话，「放松」（训练）和「放松」（机动）
会被当成同一件事；而把日型算进身份的话，勾一下「按日型」就会多出一条闹钟，
而不是改掉原来那条。

## 三、提前量多了「0 分钟」档

从前是 1 / 5 / 10 / 20 / 自定义。前四档都是从「赶上课」倒推的
（早八提前 20 分钟，临时小测提前 1 分钟），但今日页上那些格子不是课 ——
「午餐」「睡觉」「该写作业了」要的是**这一刻提醒我**。

现在是 **0 / 1 / 5 / 10 / 20 / 自定义**。0 在文案里一律写「到点提醒」，
不写「提前 0 分钟」——后者读起来像少打了个数字。

课表页的课程卡是同一个选择器，所以它也多了这一档。

## 四、细节

- 「同一门课只留一个课程闹钟」这条规则抽到了 `CardSheet.CourseAlarm`，
  课表页和今日页共用一份 —— 两个页面各写一遍，迟早有一边忘了去重，响两遍；
- 闹钟页里这类闹钟显示成：**到点提醒 / 提前 5 分钟** + 「每周三 · 午餐」；
  那一格要是被改掉了（换了模板、改了名字），会多一句「这一格已不在时间轴上」——
  和课程闹钟的「课程已删除」是同一个意思：别让一条永远不响的闹钟看上去还开着；
- 闹钟编辑页对绑定类闹钟只开放提前量 / 铃声 / 贪睡 / 节假日 ——
  时刻和响铃范围不是那里能填的，留着可填反而不生效；
- 存储多三个键 `moment` / `momentKind` / `momentDayType`，旧版本读到当作没看见；
  旧数据读出来不是 MOMENT，行为不变；
- 顺手修掉一个小瑕疵：课程闹钟的编辑页藏掉周几那一行之后，
  上面还留着一个没有内容的「重复」小标题。
