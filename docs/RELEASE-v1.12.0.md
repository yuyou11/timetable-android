# v1.12.0 课表页：点一格，看这一格**全学期**的课

本次为 v1.12.0 正式发版，新增课表页的「按格看全学期」面板，数据格式补一个可选字段。

## 新增：点课表格子 → 「这一格全学期的课」

以前点格子只弹**本周这一门课**的详情卡。但「这一周这格是什么课」格子本身已经写着答案了，
真正答不上来的是「第 9 周以后这格换成什么课了」「这门课一共上几周」——
这两个问题都要跨周次看，而格子一次只能显示一周。

现在点任意有课的一格，弹出的是一份清单：

- **一门课一张卡**：时间（按学校的节次作息推导）、教室、**老师**、周次。
- 顶部写清这一格是谁：「周三 · 第 3-4 节」；副标题「全学期 N 门课 · 第 9 教学周有 M 门」。
- **正在浏览的那一周会上的课排最前**并挂「本周」徽标；翻到别的周时徽标改写成「第 N 周」，
  不写「本周」——那一周里没有「本周」，写了就是假信息。
- **停课的课照样列出**（挂「已停课」徽标）：「这一格本来还有门课、被你停掉了」是有用信息，
  静默吞掉反而像数据丢了。
- **同一门课被拆成多条记录时合并成一张卡**（有的学校课不成对，数据里按小节拆开），
  节次范围取并集 —— 和网格里把相邻两行拼成一整块的判据完全一致。
- 面板**从被点的那个格子放大冒出**、收起时缩回格子里；课多时列表单独限高（屏高 58%）
  可滚动，不会盖住整张课表。

命中判据与课表网格、周次点阵**同一条规则**（节次区间有重叠就算占用，不是起点相等）。
三处口径一致，才不会出现「网格里画着课、点开却是空的」这种最伤人的不一致 ——
用户没有任何办法自己判断哪边是对的。

## 新增：数据格式可选字段 `teacher`（任课老师）

卡片要写老师，而原格式里没有这个字段，所以按数据格式标准补了一个**可选**字段：

```json
{
  "name": "大学英语",
  "dayOfWeek": 1,
  "nodes": [1, 2],
  "weeks": "2-4,6-17",
  "place": "教一-101",
  "teacher": "王雅琴"
}
```

- 老文件没有 `teacher` 照常导入；导出时为空则**整行不写**（文件更干净，字段顺序仍然固定）。
- 内置课表的 19 门示例课补了**虚构**老师（与课程名、教室同一性质，都是编的）。
- App 内「格式说明」、AI 提示词（现在会让 AI 从课表截图里把老师一起填上）、
  `docs/数据格式标准.md`、两份示例文件全部同步。
  示例文件那条「必须逐字节等于真实导出」的测试仍然绿 —— 它是被真实导出重新对过的。

## 兼容性

- 数据格式仍是 **timetable v5**，只多了一个可选字段：**旧版本读到它会忽略**，照常导入。
- ⚠️ **电脑版尚未同步**：PC 端不认识 `teacher`，**从电脑版导出会把这个字段丢掉**
  （解析未知字段的行为各版本不同，这一条是保守假设）。要长期两边用，电脑版需要同步这个字段；
  本次的「按格看全学期」面板也是手机版专有。
- 通知、课前提醒、时间轴、日型判定**全部未改动** —— `teacher` 不参与任何计算。
