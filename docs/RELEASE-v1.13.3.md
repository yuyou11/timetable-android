# v1.13.3 再加两道保险：App 内停止条 + 全屏响铃权限自检

v1.13.2 把响铃的停止路径补成了四条。这一版再补两条「万一」，
目标是：**任何情况下，都不该出现「只能重启手机」**。

## 1. 闹钟页顶部的「⏰ 正在响铃 · 停止 / 贪睡」

响铃期间，闹钟页最上面会冒出一条：

```
⏰ 正在响铃：起床            [贪睡 10 分钟]  [停止]
```

为什么需要它：四条出口里，**通知那条可能被系统权限挡掉**（通知权限没给时
`notify` 会静默失败），全屏界面在「亮屏且你正在用别的 App」时也不会抢前台。
但只要你**打开 App**，这一条一定在。

- 不响的时候整条是 GONE，不占任何地方（页面还是原来的样子）
- 响铃期间每秒看一眼：在别处（通知按钮 / 响铃界面）停掉了，这一条会自动消失
- 停止 / 贪睡和另外三处走完全同一套逻辑

## 2. 设置 → 闹钟 → 「全屏响铃」权限自检

Android 14 起多了一个「全屏通知」权限，系统默认只给闹钟 / 通话类应用。
App 里其它权限一直都有自检清单，唯独漏了它 —— 这一版补上：

- **已允许**：响铃时锁屏直接弹出响铃界面（大按钮停止 / 贪睡）
- **未允许**：明确告诉你「响铃只会弹一条横幅通知（点一下照样进响铃界面）」，
  并给一个「去开启」按钮直接跳到系统那个开关

注意文案口径：这一项**不是必须开**的权限 —— 没开也能完整使用（横幅 → 点一下 →
响铃界面），所以自检只做说明和跳转，不吓唬人。

## 现在的响铃出口（共五条 + 保底）

| # | 出口 | 前提 |
|---|---|---|
| 1 | 全屏响铃界面（锁屏自动弹出） | 系统给了「全屏通知」权限 |
| 2 | 通知上的「停止 / 贪睡」按钮 | 通知权限正常 |
| 3 | 划掉那条通知 | 同上 |
| 4 | **闹钟页顶部的「停止 / 贪睡」**（本版新增） | 只要你打开 App |
| 5 | 响铃界面上的大按钮 | 点通知 / 锁屏弹出后 |

外加 3 分钟自动停。**任何一条活着，声音就停得下来。**

## 兼容性

纯界面与权限自检，数据格式、闹钟行为均未改动。覆盖安装即可。
