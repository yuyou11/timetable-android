# v1.13.7 改名「时光机」，导入导出不再只叫课表

功能上和 v1.13.6 完全一样（今日页点格子、按格子设闹钟、0 分钟档），
这一版只动名字和文案 —— 但动的是**用户每天都会看到的那几处**，所以单独发一版。

## 一、App 改名：时间规划表 → 时光机

- 桌面图标、最近任务、系统「通知管理」里的应用名都会变成 **时光机**；
- 一键设系统闹钟时写进时钟应用的那条备注也改成「起床 · 时光机」；
- 权限引导里「设置 → 通知管理 → 时光机 → 此刻该做什么」这条路径跟着改
  （不改的话，用户照着走会找不到这个 App）。

**包名 `com.yxz.timetable` 没有改。** 改包名在系统眼里就是另一个应用：
装上去会变成两个图标，原来的课表、闹钟、设置一个都带不过去。
「时间规划表」本来就是那份 Word 文档的名字，现在只是图标下面那四个字换了。

## 二、导入 / 导出不再只叫「课表」

设置页那两个按钮改成了 **导入数据 / 导出数据**。

原来叫「导入课表」，但这条路径带的不只是课表 —— 还有学期（名称 / 起始日 / 总周数）、
作息模板、日型配置、节次结构。只改作息的人看到「导入课表」，会以为这条路走不通。

跟着一起改的：

| 位置 | 之前 | 现在 |
|---|---|---|
| 设置页按钮 | 导入课表 / 导出课表 | **导入数据 / 导出数据** |
| 导出二选一 | 仅课表 / 课表 + 作息（模板与启用的日型） | **仅课程 / 课程 + 作息（模板与启用的日型）** |
| 导出的文件名 | `课表-2026 秋.json` | `课程-2026 秋.json` |
| 清空课程的提示 | 建议先「导出课表」备份 | 建议先「导出数据」备份 |
| AI 向导第 5 步 | 设置 → 数据 → 导入课表 | 设置 → 数据 → 导入数据 |
| 选错文件时的提示 | 请选择从 App 里导出的 .json 课表文件 | 请选择从 App 里导出的 .json **数据**文件 |
| 给 AI 的「报错修复」提示词 | 你刚才生成的时间规划表 JSON 导入失败了 | 你刚才生成的 JSON 导入失败了 |

课表页那个标签仍然叫「课表」—— 那一页确实只有课表，没有跟着改。
