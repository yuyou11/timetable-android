# v1.13.2 修复：只响一次 + 响铃时一定有地方能关掉

两个都是实测报上来的问题。

## 1. 七天全不选 = 只响一次（以前被拦住不让存）

一周的勾**全部取消**，本来就是「不重复、只响一次」的意思 —— 列表摘要里也一直
写着「不重复」，但保存时被一句「至少选一天」挡了回去。**文案和逻辑不一致，是 bug。**

现在真的实现了：

- 七天全部取消 → 存下来时把「下一次那个时刻」算成**具体日期**固定住
  （今天这个点还没过就是今天，过了就是明天）。对话框顶部会写清：
  「只响一次：11 月 19 日（周四）07:00」
- 预设里多了一个「**只响一次**」按钮，设一次性闹钟不用手动取消七个勾
- 响过之后**自动关闭**（不关的话第二天同一时刻又会响，那就成了每天响）
- 列表里显示「只响一次 · 11 月 19 日」

⚠️ 只响一次的闹钟**不套「智能识别节假日」**：用户明确指定了「就这一次、就这个点」，
静默跳过等于让他误事。要跳过节假日，就别用只响一次。

## 2. 响铃时**一定有一个能关掉它的地方**

第一版只在通知上放了「停止 / 贪睡」。实际遇到的情况是：闹钟响了、通知没出现
（通知权限被系统挡掉时 `notify` 会静默失败），于是**声音一直响、屏幕上没有任何
能关它的东西**，最后只能重启手机。

教训：**响铃这种「正在发生的坏事」，停止入口不能只挂在一条链路上。**
现在有四条，任何一条活着都能让声音停下来：

1. **全屏响铃界面**（新增）：锁屏上直接亮屏弹出 —— 60sp 的大时钟、
   占满宽度的「停止」大按钮、以及「贪睡 N 分钟」。点通知也进这里。
2. 通知上的「停止 / 贪睡」两个按钮
3. **划掉那条通知也算停**（deleteIntent 接管）
4. 3 分钟自动停

全屏界面用 `setFullScreenIntent` + `USE_FULL_SCREEN_INTENT`（闹钟类应用的标准用法）。
拿不到这个权限也不影响，另外三条路都还在。

## 兼容性

- 数据格式不变；闹钟数据里多了一个可选的 `once` 字段，老数据没有它照常读。
- 覆盖安装即可，闹钟与课表数据都保留。
