# v1.13.5 闹钟可靠性、页面状态保持与界面收敛

这个版本没有新页面，主要是把「会误事的地方」修掉，并把界面收敛成一套统一的视觉语言。

## 一、闹钟：先保证它真的会响

### 响铃不再被休眠掐断

以前响铃只设了 `USAGE_ALARM`，没有 wakelock。屏幕熄灭后 CPU 睡下去，部分机型
会把进程冻住，声音就断了 —— 通知还在，但人已经被吵不醒。

现在：

- `MediaPlayer.setWakeMode(PARTIAL_WAKE_LOCK)`，只在响铃这几分钟持有；
- 响铃时申请一次 `AUDIOFOCUS_GAIN_TRANSIENT`，停止时释放，不和音乐混在一起；
- 音量 20 秒内从 15% 渐强到 100%（突然满音量会把人吓醒）。

Manifest 相应补了 `WAKE_LOCK` 权限。

### 同分钟的多个闹钟一起贪睡

「起床 + 吃药」设在同一分钟很常见。以前按贪睡只记第一个 id，第二个直接丢了。
现在 `snoozeAlarmIds` 存一整批，到点一起响、一起贪睡。

### 导入课表后，课程闹钟不再绑错课

课程闹钟按 `courseId` 绑定，而导入会重编号整张表。以前：

- 合并课表：所有课的 id 都变 → 闹钟可能指向另一门课，**在错误的时间响**；
- 替换课表：旧 id 全部失效 → 闹钟变孤儿，静默不响。

现在：

- 合并时**只给新加入的课分配 id**，现有课程的 id 不动；
- 替换时按「课名 + 星期 + 起始节」把闹钟重映射到新 id，接不上的停用；
- 清空 / 恢复内置课表时，课程闹钟统一停用；
- 导入结束后同时重排通知链与用户闹钟链。

### 打开 App 就恢复闹钟

系统「强行停止」会撤销 App 的所有闹钟。以前要进一次闹钟页才会重排，现在
`MainActivity.onResume` 两条链一起排。

### 新增：错过提示 / 上次响铃 / 跳过下一次

- 排程时记下「系统里排着的下一次」，真响了才清；超过 5 分钟没清就判定错过，
  闹钟页显示「错过：11 月 18 日 07:00 的『起床』没有响」；
- 自动停之后保留一条「上次响铃 07:00 · 起床」，24 小时内有效；
- **长按任意闹钟行 → 跳过下一次**（只跳过那一天，过后自动恢复）。

### 其它

- 响铃时长可调：设置 → 闹钟 → 响铃时长（1 / 3 / 5 / 10 分钟）；
- 闹钟页会提示两类「会影响响铃」的问题：通知权限未开、闹钟音量为 0；
- 课程闹钟按「真实下次响铃时间」排序，不再按 id；
- 过期的一次性闹钟标记为「已过期」；
- 状态栏闹钟图标点进去直接停在闹钟页；
- 时间选择器从 spinner 改为 clock；
- 空 URI 的铃声文案从「静音」改回「默认（系统铃声）」（它本来就是跟随默认）。

## 二、页面状态与界面

- **切页不再重建**：底部标签从 `replace` 改为 `add + hide/show`，
  课表翻到第 12 周、设置页滚动位置，切走再回来都还在；
- 卡片圆角 / 描边 / 间距 / 字号收敛成一套；「此刻」改成整页唯一的强调色卡片；
- 底部导航跟随主题染色，深色模式下按钮文字改用深色（夜里强调色更亮）；
- 文案删减：设置页长说明、AI 向导 10 步压到 6 步、各确认弹窗只留后果与撤销方式。

## 三、存储

- 读取失败不再静默回退：逐条解析，坏一条跳过一条；设置页顶部显示「读取失败」提示；
- 清空 / 恢复课表时，绑在课程上的闹钟会停用，避免「看着开着、永远不响」。

## 四、其它

- 去掉 `resourceConfigurations` 里的 `"en"`（工程从来没有英文资源）；
- 单元测试从 380 条增加到 **387** 条（新增跳过下一次、过期、课程闹钟重映射）。
