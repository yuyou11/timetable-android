# v1.12.1 课表页：空格子也能点，整学期没课就是一张「自习卡」

本次是 v1.12.0 的补丁版，只动课表页的点击行为。数据格式、通知、时间轴全部未变。

## 新增：空格子可点

课表上的空格子其实有两种意思：

- 「**这一周**这一格没课」—— 别的周可能在这格上排了课
- 「**整学期**这一格都没课」—— 那这段时间本来就该是自习

以前只有有课的格子能点开，于是第一种情况的问题（「第 9 周以后这格换成什么课了」）
在空格子上根本问不出来。现在**任意格子都能点**：

- 这一格别的周有课 → 照旧弹出课程卡清单，每张卡带「第 N 周」徽标，
  各自写清这门课在第几周上（正在浏览的那一周会上的一门仍然排最前）
- 整学期都没课 → 弹出一张**自习卡**

## 新增：自习卡

自习卡的内容取自**当天实际生效的日型模板**里、覆盖这一节的那个占位格 ——
和今日页、通知栏同一条链路（`TimelineEngine.dayType` → `TemplateSet.blockAt`），
所以三处说的必然是同一件事，不会出现「课表页说自习、通知栏说空档」。

```
自习 / 轻松跑                    [无课]
周三 · 第 7-8 节
──────────────────────────────
时间   15:55 – 17:30
周次   全学期都没有课
```

- 卡片名字就是模板占位格的备注（「自习」「自习 / 轻松跑」「晚自习」…）；
- 手工给占位格写了地点的话，教室那一行也会显示；没有就把这一行收起，不写「未注明」；
- 周六 / 周日 / 无课休息日的模板里**本来就没有课表格子**，这时退回
  「自习」+ 内置作息时刻（与课表左边那列节次时间同源），不会出现空卡。

## 界面没有变

空格子在视觉上**依然什么都没有** —— 没有虚线、没有圆点、没有占位符，只是变得可以点。
这一条是刻意的：绝大多数格子是空的，给它们都加标记会非常吵。

## 兼容性

- 数据格式仍是 timetable **v5**，本次未动（`teacher` 字段见 v1.12.0 的说明）。
- 通知、课前提醒、时间轴、日型判定全部未改动。
- ⚠️ 电脑版仍未同步（本次是手机版专有的点击交互）。
